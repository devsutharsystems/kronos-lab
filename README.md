# Kronos Lab

A pre-registered test of whether Kronos-small predicts 1-hour crypto candle direction better than a coin flip and trivial baselines, plus a static GitHub Pages site.

**Status:** Phase 0 (PRD, scaffold, guardrails). No results yet.
