## Seed convention

`torch.manual_seed(seed)` immediately before every forecast call (seeds CPU and MPS). Spike: warm-up seed 0; timed repeat r seed 1000+r; IND11 unit r uses 1000+100r+j. Proposed for the real run: seed = 1_000_000 * pair_index + origin_index (one seed per origin).
