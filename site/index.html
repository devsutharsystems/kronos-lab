In plain English

Kronos is a model trained to continue price candles. We asked one narrow question: given the recent past of a crypto pair, can it call the direction of the day better than a coin flip, and better than a rule that always says up? We wrote the test down before running it, ran it once on a fixed set of days, and report what it found, including when that is nothing.

The Evidence page shows how the numbers arise, the Game lets you try the same task, the Method page quotes the plan, and the Limits page lists what this cannot tell you.
